# Gorka-cloud

Легковесное облачное хранилище изображений с генерацией QR-кодов для быстрого доступа с телефона через WireGuard. 

Custom made for Sortyaga gorka

## Как работает
- На хосте разворачивается в Docker compose
- Выводится в интернет пробросом порта на роутере
- Через Wireguard строит туннель, с помощью конфига можно подключаться откуда угодно
- Хранит фотографии на сервере, обеспечивает доступ к ним по QR-коду
- Загрузка фотографий и генерация QR кодов выполняется через web-страницу

## Характеристики
- **Стек**: Nginx (Alpine) + FastAPI (Python 3.12) + SQLite + TailwindCSS.
- **Потребление ресурсов**: ~60–90 МБ ОЗУ в рабочем режиме (лимит контейнеров — до 768 МБ).
- **Разделение прав**:
  - Панель управления (`/`) защищена PIN-кодом (`ADMIN_PIN` в `docker-compose.yml`).
  - Страница по QR-коду (`/v/<id>`) работает в режиме **Read-Only** (только просмотр и кнопка скачивания оригинала).

## Что нужно для работы
- ОЗУ: 2ГБ
- Процессор: 2 ядра
- Wireguard на хосте
- Белый IP адрес
- Linux с ядром не старше 6.0
