# Gorka-cloud

Легковесное облачное хранилище изображений с генерацией QR-кодов для быстрого доступа с телефона через WireGuard.

## Характеристики
- **Стек**: Nginx (Alpine) + FastAPI (Python 3.12) + SQLite + TailwindCSS.
- **Потребление ресурсов**: ~60–90 МБ ОЗУ в рабочем режиме (лимит контейнеров — до 768 МБ).
- **Разделение прав**:
  - Панель управления (`/`) защищена PIN-кодом (`ADMIN_PIN` в `docker-compose.yml`).
  - Страница по QR-коду (`/v/<id>`) работает в режиме **Read-Only** (только просмотр и кнопка скачивания оригинала).
